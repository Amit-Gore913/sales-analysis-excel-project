Performed sales data analysis in Excel using Pivot Tables to evaluate regional, category, and product performance.
# Sales Performance Analysis Using Excel

## Project Overview

This project analyzes retail sales data using Microsoft Excel and Pivot Tables.

## Tools Used

* Microsoft Excel
* Pivot Tables

## Key Findings

* West Region generated the highest sales.
* West Region generated the highest profit (108,418.45).
* Technology was the top-performing category.
* Phones were the highest-selling sub-category.
* Total Sales analyzed: 2,297,200.86
